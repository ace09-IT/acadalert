# AcadAlert: AI-Powered Academic Risk Detection System

**AcadAlert** is a web-based system designed for Universidad de Dagupan to identify students at risk of academic failure. By utilizing AI to analyze grades and attendance, the system provides early warnings and structured intervention workflows for Academic Heads and Guidance Counselors.

## 🚀 Features by Role
*   **Admin:** Campus-wide oversight, user management, risk threshold configuration, and audit logs.
*   **Academic Head:** Department-level risk scoring, AI intervention generation, and student escalation.
*   **Guidance Counselor:** Case management, session logging, and intervention tracking.
*   **Student:** Self-service portal to view personal risk status, grades, attendance, and alerts.

## 🛠️ Tech Stack
*   **Backend:** Laravel 12 (PHP 8.2)
*   **Database:** MySQL (for derived data)
*   **Mock API:** Node.js & json-server (for raw academic data)
*   **AI Engine:** Google AI Studio (Gemini)
*   **Frontend:** Bootstrap 5, Chart.js, Custom CSS

## 💻 System Requirements
Before running this project, ensure you have the following installed:
*   [XAMPP](https://www.apachefriends.org/) (PHP 8.2 or newer, MySQL)
*   [Node.js](https://nodejs.org/) (LTS version)
*   [Composer](https://getcomposer.org/)
